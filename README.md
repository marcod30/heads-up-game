# ¡Adivina! 🎉

Juego web de adivinar palabras para jugar en grupo con el móvil, al estilo *Heads Up!*: quien adivina se pone el móvil en la frente, el resto le describe la palabra y, al girar el móvil, se marca acierto o se pasa a la siguiente.

Es una PWA hecha con React, Vite y TypeScript, sin backend: se juega desde el navegador, se puede instalar en el móvil y funciona sin conexión.

## Desarrollo

```bash
npm install
npm run dev
```

Se publica automáticamente en GitHub Pages con cada cambio en `main`.
